A window switcher for macOS

Windows-style Alt-Tab for the Mac.

Switch windows, not just apps. Windows from all apps, in one thumbnail grid. Hold the shortcut, choose a window, release to switch.

The default is Option+Tab. On a PC keyboard connected to a Mac, Alt acts as Option: physically, Alt+Tab.

Download for macOS View on GitHub

Free download from GitHub Releases, signed with Developer ID and notarized by Apple. Unzip and move JustTab to Applications. With Homebrew: brew install --cask shuaige121/tap/justtab. Or build from source.

Requires macOS 13+ and Accessibility permission. Live thumbnails need macOS 14+ and Screen Recording permission; otherwise, app icons are shown.

Option + Tab

Hold. Choose. Release.

01 / Open

Hold Option, press Tab.

The previous window is selected when the switcher opens.

02 / Choose

Move through the grid.

Keep holding. Tap Tab or the arrow keys to move. Shift+Tab goes back.

03 / Switch

Release to switch.

Esc cancels. Clicking a thumbnail also switches to that window.

One job: switching windows.

  • Most recently used first. A quick press and release toggles between your two most recent windows.
  • Minimized windows included. They are shown dimmed.
  • A grid that fits. Cells shrink so every listed window fits on screen.
  • Your shortcut. Record any key plus one or more of Control, Option, Shift and Cmd from the menu bar via Change Shortcut…; Esc cancels recording. The only other setting is Launch at Login.
  • In the menu bar. No Dock icon.
  • Swift + AppKit. Zero third-party dependencies, about 2,600 lines of Swift, about 520 KB on disk.
  • Apps hidden with Cmd-H are listed; choosing a window brings the app back.
  • Windows on other desktops (Spaces) are listed; choosing one switches to that desktop.
  • The switcher opens on the display that has the mouse pointer.
  • After each switch, JustTab checks that the chosen window came to the front and retries once if needed.

No networking code.

No telemetry, no account, no update checks. Accessibility permission is required. Live thumbnails require macOS 14+ and Screen Recording permission; without them, app icons are shown.

Questions, answered.

Why not on the Mac App Store?

App Store apps must be sandboxed. A sandboxed app cannot use the Accessibility API to list or focus other apps' windows, as Apple Developer Technical Support explained on the Apple Developer Forums (2024, 2025). Window switchers of this kind are distributed directly. JustTab is not on the Mac App Store.

Download it from GitHub Releases: it is signed with Developer ID and notarized by Apple.

Can it replace Cmd-Tab?

Yes. Open Change Shortcut… from the menu bar and record Cmd+Tab. It replaces the built-in app switcher while JustTab runs. Any key plus one or more of Control, Option, Shift and Cmd can be recorded. Esc cancels recording.

On macOS, Cmd-Tab switches apps; Cmd-` cycles windows of the current app only.

Does it phone home?

No. The app contains no networking code: no telemetry, no account, no update checks.

Which windows are listed?

Windows from all apps, including minimized windows, shown dimmed.

Windows of apps hidden with Cmd-H are listed; choosing one brings the app back.

Windows on other desktops (Spaces) are listed; choosing one switches to that desktop.

Does it use private macOS functions?

The source uses exactly one private macOS function, _AXUIElementGetWindow, to match an accessibility window to its window ID.

JustTab is a stripped-down fork of alttab-macos by Sergio Farfan (MIT), itself inspired by AltTab by lwouis.
