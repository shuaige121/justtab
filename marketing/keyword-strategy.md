# Keyword strategy (internal)

Use descriptive phrases grounded in the supplied facts. No search-ranking research was performed and no ranking outcome is promised.

## Phrase bank

| English | Chinese | Authority |
| --- | --- | --- |
| window switcher for macOS | macOS 窗口切换器 | F1, F2, F12 |
| switch individual windows | 按窗口切换 | F2 |
| windows from all apps in one grid | 在同一个网格里选择各个 App 的窗口 | F2 |
| Option+Tab by default | 默认 Option+Tab | F4 |
| Alt+Tab on a PC keyboard connected to a Mac | PC 键盘接 Mac，Alt 键等同于 Option | F4 |
| free forever, open source | 永久免费、开源 | F9, F17 |
| build from source with full Xcode | 用完整版 Xcode 从源码构建 | F13 |

Use the first phrase in descriptive metadata and the individual-window pitch in the README and site. Pair any mention of live thumbnails with macOS 14+ and Screen Recording permission, or keep that requirement in the same post/page (F12).

Repository topics: `macos`, `window-switcher`, `swift`, `appkit`, `menu-bar-app`, `open-source`, `mit-license`, `keyboard-shortcuts` (F2, F3, F5, F9, F11, F12).

Do not use another product's name as a topic, hashtag or keyword. The only upstream names in public copy belong in the full F9 credit. No comparisons, keyword stuffing, invented hardware support or unsupported performance adjectives. App Store availability belongs in the F19 FAQ, not an obsolete installation claim.
