# Keyword strategy (internal, never published)

Goal: people searching for Windows-style Alt-Tab on a Mac can find JustTab, without JustTab borrowing any other product's name.

## 1. Landscape (internal only)

- "AltTab" is the name of an existing open-source project (lwouis/alt-tab-macos, GPL-3.0, alt-tab.app). It ranks for "alt tab mac" searches.
- A paid Mac App Store app called "AltTab Switcher" also exists.
- "Alt-Tab" (hyphenated, two words) is also the generic Windows keyboard term. That generic use is what we target.
- The name is taken, so JustTab stays JustTab. We win on description and on the F17 commitment, not on a name.

## 2. Rules

1. The product name is always **JustTab** (F1). Never shorten, respell or extend it toward another name.
2. Use only generic descriptive phrases. "Alt-Tab" appears only as the Windows keyboard term (hyphenated, with the word "Windows-style" or "on Windows" nearby, or as the physical key combination Alt+Tab on a PC keyboard, F4).
3. No comparison wording, no "alternative to", "like X", "better than", "vs".
4. The only mention of another project is the required F9 credit (alttab-macos by Sergio Farfan, inspired by AltTab by lwouis). It is attribution, stays in the credit line, and is never placed in a title, tagline, topic or tag.
5. Do not mention the App Store or Homebrew except where the install note says there is no listing (F13).

## 3. Phrase bank

English (all supported by O1, F2, F3, F4, F15):
- Windows-style Alt-Tab for Mac
- Alt-Tab for Mac, switch windows not apps
- switch windows, not just apps
- window switcher for macOS
- hold Option+Tab, release to switch (Alt+Tab on a PC keyboard)
- free forever, open source window switcher

Chinese (full-width punctuation in prose):
- Mac 像 Windows 一样 Alt+Tab 切换窗口
- Mac 切换窗口 / Mac 窗口切换
- 切换窗口，而不只是切换 App
- 从 Windows 转 Mac 的窗口切换器
- 永久免费、开源的 Mac 窗口切换器

Positive message to pair with the keywords: free forever, open source, no paywall, no Pro tier, no upsell (F17); one job, one real setting (F2, F5). Say it plainly, never as a contrast with anyone.

## 5. Phrases to avoid

- "AltTab", "Alt Tab" as one brand-like token, "alttab-macos" outside the credit line, "AltTab Switcher", "alt-tab.app".
- Any "alternative", "like", "instead of", "vs", "better than", "fork of the popular" framing.
- Hashtags or tags that are another product's name.
- Keyword stuffing: each phrase appears naturally once or twice per page.
- Anything not in the fact list to pad keywords (for example "fast", "lightweight", "best", platform or hardware claims).

## 6. Limits of this plan

- No search was run; nothing here is measured. Ranking against the established project for "alt tab mac" is not promised or implied.
- Phrases are expected to help mainly through GitHub search, Xiaohongshu and V2EX, where descriptive text and tags match queries.
